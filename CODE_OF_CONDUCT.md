# Code of Conduct

**English** · [Português (Brasil)](#português-brasil)

## English

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone who takes part in issues, pull requests and discussions is expected to follow it.

To report unacceptable behavior, use the private reporting form at [https://github.com/Borges360/pi-cost-profiler/security/advisories/new](https://github.com/Borges360/pi-cost-profiler/security/advisories/new) and start the title with `Conduct:`. Reports are read only by the maintainer and handled as described in the Covenant's enforcement guidelines.

## Português (Brasil)

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/). Todas as pessoas que participam de issues, pull requests e discussões devem segui-lo.

Para relatar um comportamento inaceitável, use o formulário privado em [https://github.com/Borges360/pi-cost-profiler/security/advisories/new](https://github.com/Borges360/pi-cost-profiler/security/advisories/new) e comece o título com `Conduct:`. Os relatos são lidos apenas pelo mantenedor e tratados conforme as diretrizes de aplicação do Covenant.
