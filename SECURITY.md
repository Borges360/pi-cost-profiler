# Security

**English** · [Português (Brasil)](#relato-de-vulnerabilidade)

Pi Cost Profiler runs inside Pi with the operating-system privileges of the user who started Pi. It is not a sandbox. The README section **Privacy and security** describes what the extension reads, stores and sends.

## Reporting a vulnerability

Do not open a public issue. Report privately through [GitHub private vulnerability reporting](https://github.com/Borges360/pi-cost-profiler/security/advisories/new) (**Security** → **Report a vulnerability**).

Include the version or commit, the Pi version, your operating system and the steps that reproduce the problem. Do not attach credentials, tokens, transcripts or raw local state; describe them or use synthetic values.

You will receive an acknowledgement after the report is read. Fixes are released from the latest version; older versions do not receive backports.

## Relato de vulnerabilidade

Não abra issue pública. Relate em particular pelo [relato privado de vulnerabilidade do GitHub](https://github.com/Borges360/pi-cost-profiler/security/advisories/new) (**Security** → **Report a vulnerability**).

Informe a versão ou o commit, a versão do Pi, o sistema operacional e os passos que reproduzem o problema. Não anexe credenciais, tokens, transcrições nem estado local bruto; descreva-os ou use valores sintéticos.

Você receberá uma confirmação depois que o relato for lido. As correções saem a partir da versão mais recente; versões antigas não recebem backport.
